# Getting Started with Create React App

To run this APP follow this steps:

1. open new terminal inside the myapp folder

2. to install everything write inside the terminal:

### `npm install @testing-library/jest-dom@^5.17.0 @testing-library/react@^13.4.0 @testing-library/user-event@^13.5.0 axios@^1.4.0 chart.js@^4.4.0 react@^18.2.0 react-chartjs-2@^5.2.0 react-dom@^18.2.0 react-icons@^4.10.1 react-redux@^8.1.2 react-router-dom@^6.15.0 react-scripts@5.0.1 react-use@^17.4.0 redux@^4.2.1 sass@^1.66.1 styled-components@^5.3.10 web-vitals@^2.1.4`

3. To run the app write inside the terminal:

### `npm start`
